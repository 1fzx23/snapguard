SnapGuard

为任意目录生成不可变快照，检测变更、校验完整性、实时监控。

GitHub 源码 ↗ 返回工具箱 ↗

核心能力

📸

快照

记录目录中每个文件的路径、大小、修改时间与 SHA-256。

🔍

对比

diff 命令输出新增、删除、修改与重命名，智能识别内容未变的路径变更。

✅

校验

重新计算哈希，检测文件损坏、静默篡改或备份不完整。

👀

监控

watch 命令实时监听变化，优先 OS 原生事件，无依赖时自动轮询。

安装与使用

git clone https://github.com/1fzx23/snapguard.git
cd snapguard

python snapguard.py init .
python snapguard.py snap --label "before-upgrade"
python snapguard.py diff latest
python snapguard.py verify latest

设计亮点

核心功能仅使用 Python 标准库，无需安装额外依赖；watchdog 作为可选依赖提升实时监控体验。快照文件为纯 JSON，便于版本控制与二次处理。自动跳过 .snapguard 自身仓库，避免快照循环。
